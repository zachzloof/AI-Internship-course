**Q: What is the blockchain?**

Expected: The blockchain is a public, distributed ledger that records every Bitcoin transaction; nodes each keep a copy, and transactions are grouped into cryptographically linked blocks.

Actual: The blockchain is a public, distributed ledger that records every transaction ever made on the Bitcoin network. It is maintained by thousands of computers, called nodes, each of which keeps its own copy of the entire transaction history. New transactions are grouped into "blocks," which are cryptographically linked to previous blocks, forming a chain. This structure makes tampering with past transactions extremely difficult, as altering any transaction would require redoing the work for every subsequent block on a majority of the network simultaneously.

**Q: How does Bitcoin mining work?**

Expected: Miners compete to solve a Proof-of-Work puzzle; the first to solve it adds the next block and earns newly created bitcoin plus transaction fees.

Actual: Bitcoin mining involves participants called miners who use specialized computer hardware to solve a complex mathematical puzzle through a system known as Proof-of-Work. This process requires substantial computational effort to find a valid solution, which is easy for others to verify. The first miner to solve the puzzle gets to add the next block to the blockchain and receives a reward, called the "block subsidy," which includes newly created bitcoin and transaction fees from that block. Mining difficulty adjusts approximately every two weeks to ensure that a new block is added roughly every ten minutes, regardless of the total computing power on the network.
